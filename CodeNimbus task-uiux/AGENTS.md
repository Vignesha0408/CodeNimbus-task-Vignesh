# Invitation Nation - Premium Frontend Website

A complete, advanced frontend website for creating beautiful digital invitations with premium UI/UX design, inspired by Invitation Nation.

## Project Structure

```
/project
├── index.html          # Main HTML file
├── css/
│   └── style.css      # Advanced styling with animations and effects
├── js/
│   └── script.js      # Interactive JavaScript functionality
└── images/            # Directory for images (using Unsplash for random images)
```

## How to Use

1. Open `index.html` in a web browser
2. Experience the premium hero section with 3D effects
3. Navigate through sections using the smooth scrolling navigation
4. Browse premium templates with real images
5. Filter templates by category with animated buttons
6. Click "Use Template" to load settings into the custom editor
7. Customize invitations with real-time preview
8. Interact with all UI elements to experience the premium UX
